## DM3. Gia tri gia tang - DAT (tai lieu), can gop 1 doc dinh vi

Da co: `docs/research/COMPETITIVE-ANALYSIS.md`, `COMPETITIVE-GAP-2026-10-28.md`,
`PM-REPORT-2026-09-30-ecosystem.md`, deck PROPOSAL.

De "noi duoc tai sao can" truoc nha truong/So can 1 doc gon tra loi 3 cau:

- **Tai sao can**: GVCN mat ~30-40% thoi gian tuan vao giay to thu cong (so
  diem, so chu nhiem, bao cao); du lieu phan tan Excel/Zalo; bao cao So
  lam tay hang quy; TT 15/2026 + Luat 91/2025 bat buoc so hoa co kiem soat.
- **Truong can gi de trien khai**: tai khoan GV/HS (import Excel co san
  `scripts/khoi-tao-truong.xlsx`), khong can cai dat (SaaS), khong can
  server tai truong, module bat/tat theo nhu cau + gia.
- **Khac biet**: SMAS/vnEdu/MISA manh quan tri nhung yeu sach GV; he nay
  bat dau tu cong viec hang ngay cua GVCN (diem danh 1 cham, bao cao ngay
  cho BGH 1 nut, AI goi y nhan xet), module ban le nhu phu kien, du lieu
  chuan MOET de noi CSDL nganh.

-> Viec: gop thanh `docs/positioning/GIA-TRI-GIA-TANG.md` (CR-116-W1).

## DM4. UX - chuc nang hay dung hien the - DAT mot phan, can nang cap

Hien trang:

- Dashboard GVCN (`/dashboard`): 2 nut hanh dong nhanh (Diem danh lop, Ghi
  nhan tuyen duong) + 10 KPI StatCard, moi card link toi man hinh tuong ung.
- Dashboard BGH (`/school/dashboard`): radar + kpi cards.
- Portal PH/HS: trang chu co link den tung muc (diem, chuyen can, tin
  nhan, hoc ba, bai thi).

Gap so voi yeu cau "chuc nang quan trong/co ban/hay dung nhat hien thi
rieng dang the ngay man hinh user":

- Chua co strip the "Chuc nang hay dung" ca nhan hoa theo vai tro - hien
  chi la 2 nut co dinh cho GVCN, cac vai tro khac chua co.
- Chua do tan suat dung de tu xep thu tu (chi can static theo vai tro
  cung du dot dau).

-> CR-116-W2: khoi "Chuc nang hay dung" tren dashboard moi vai tro
(static theo vai tro truoc, ca nhan hoa sau neu can).

## DM5. Ket noi CSDL Bo + chuyen du lieu tu VNEDU - GAP LON

Da co nen tang:

- Import Excel toan dien (hoc sinh, giao vien, diem, chuyen can, khoi tao
  truong) - `src/lib/excel.ts` + cac man hinh Import.
- Hoc ba XML SCN-QD3016-v1 export co ky xac thuc - san sang gui dinh dang
  chuan khi Bo cong bo endpoint.
- Integration framework (`/school/integrations`): connectors, outbox,
  retry, cron worker - nen tang de noi API ben ngoai.

Thieu de trien khai thuc te:

- **Import tu VNEDU**: chua co mapper doc file export VNEDU (SMAS/vnEdu
  xuat Excel/XML rieng) - can tool "Import tu vnEdu/SMAS" map cot tu dong.
- **Connector CSDL nganh Bo**: framework co nhung chua co connector
  dinh nghia cho API CSDL nganh GD&DT (Bo chua mo API cong khai; khi mo,
  can connector + auth theo spec Bo).
- **Ma dinh danh quoc gia**: can truong luu ma dinh danh ca nhan
  (cccd/dinh danh dien tu) cho HS/GV de dong bo CSDL nganh - khao sat
  schema hien co truoc khi them.

-> CR-116-W3: mapper vnEdu import + spec connector CSDL nganh + truong
ma dinh danh.

## DM6. Bao mat du lieu - provider phap nhan VN + consent theo tuoi - GAP

Da co: consent_records (5 muc dich, kenh, thu hoi), data_requests, DPIA
v2, ho so chuyen du lieu, redact PII truoc khi AI.

Ba gap:

- **Consent chua phan tuoi**. Quy tac can ap: <14 tuoi bat buoc dong thuan
  PHHS; >=14 HS tu dong thuan (van nen ghi kem PH). Hien `consent_records`
  chi co (student, purpose, channel) chua suy dien tu `date_of_birth` -
  can cot tuoi suy dien + UI canh bao khi ghi consent sai doi tuong.
- **Du lieu dang o provider nuoc ngoai**: Supabase (region ngoai VN),
  Vercel (US), Resend (US), AI providers (US). Theo huong "provider co
  phap nhan VN": phuong an thuc te la duong 2 lan -
  (a) ngan han: dien region that + hoan thien ho so chuyen du lieu (da
      san khung, chi thieu so region tu dashboard);
  (b) dai han: chuyen DB sang cloud co phap nhan VN khi khach hang la
      truong cong yeu cau (Viettel IDC/VNPT/CMC/FPT - Postgres tu quan
      ly hoac Supabase self-host tren VPS VN; app Next.js van chay duoc).
- **Danh gia ATTT/A05**: du lieu tre em la "du lieu quan trong" theo
  ND 53/2022 - khi trien khai quy mo So/toan quoc se can dang ky danh
  gia an ninh mang voi Cuc An ninh mang (A05). Khong lam duoc bang code -
  can ho so he thong + don vi tham dinh. Ghi vao roadmap phap ly.

-> CR-116-W4: consent theo tuoi suy dien tu DOB.
-> Tai lieu chien luoc hosting VN: `docs/positioning/` cung W1.
